# Personal Expense Management System

The Personal Expense Management System is a web-based application designed to help users track and manage their daily financial activities. By providing tools for recording transactions, setting budgets, and visualizing financial data, the system enables users to maintain better control over their spending habits.

## Project Overview
This project addresses the growing need for personal financial discipline among students and professionals. It offers a comprehensive suite of features to monitor income and expenses, analyze spending patterns through intuitive charts, and ensure financial goals are met through a robust budget alert system.

## Project Objectives
- Develop a functional web platform within a 7 to 9-week timeframe.
- Implement core features including transaction logging, categorization, and reporting.
- Ensure data security through user authentication and personal account management.
- Provide actionable insights through visual data analysis (Pie and Bar charts).

## Tech Stack
The application is built using the MERN stack:
- Frontend: React + Vite
- Backend: Node.js + ExpressJS
- Database: MongoDB

## Main Features

### User Account Management
- User registration and secure login.
- Password recovery and update functionality.
- Personal profile management.

### Income and Expense Management
- Record, edit, and delete income and expense transactions.
- Detailed transaction information: Amount, Date, Category, and Notes.
- Pre-defined categories: Salary, Bonus, Food, Shopping, Transportation, Bills, etc.

### Category Management
- Create, edit, and delete custom categories.
- Classification of categories into Income or Expense types.

### Statistics and Reporting
- Automated calculation of total income, expenses, and balance.
- Data analysis by timeframes (Day, Month, Year).
- Visual Reports:
    - Pie Chart: Expense distribution by category.
    - Bar Chart: Monthly comparison between income and expenses.

### Budgeting and Reminders
- Set monthly limits for specific categories.
- Real-time tracking against budget goals.
- Automated alerts for budget thresholds and bill payment reminders.

### Data Portability and Search
- Advanced filtering by date, category, and amount range.
- Export financial reports to PDF and Excel formats.
- Data backup and restoration capabilities.

## Target Users
- Students managing monthly allowances.
- Working professionals tracking living expenses and savings.
- Individuals seeking to optimize their financial health.
