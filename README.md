Project Title:  Personal Expense Management System
I. Project Overview
The Personal Expense Management System is a web-based application that helps users track and manage their daily income and expenses effectively. Users can record transactions, categorize spending, set budgets, and view financial reports through intuitive visualizations.
In addition, the system provides reminders for upcoming payments and alerts when spending exceeds limits, helping users maintain better financial control. The project is designed with a focus on usability, performance, and future scalability.
II. Project Objectives
To develop a web-based personal expense management system that allows users to register, log in, record transactions, categorize expenses, and monitor their financial activities.
The system must support core functionalities, including user account management, adding/editing/deleting transactions, expense categorization, budget setting, and financial reporting through charts.
The project will be carried out by a small team within 7 to 9 weeks using common web technologies such as Node.js, React, and MongoDB, ensuring feasibility.
The system addresses the increasing need for personal financial management among students and working individuals, helping improve spending habits.
The main features of the system will be completed within 7 to 9 weeks, including analysis, design, development, and testing.
III. Target Users
The system is designed for students, employees, and individuals who want to manage their personal finances, as well as anyone who wishes to monitor and optimize their spending.
IV. Main Features
User Account Management
Purpose: To allow users to access and use the system.
Functions:
Register an account
Log in
Log out
Forgot / change password
Update personal information
Income Management
Purpose: To record all incoming funds received by the user.
Functions:
Add income
Edit income
Delete income
View income list
Categorize income
Income Information:
Amount
Date
Income category (Salary/Bonus/Additional income)
Notes
Expense Management
Purpose: To track all user expenses.
Functions:
Add expense
Edit expense
Delete expense
View expense list
Categorize expenses
Expense Information:
Amount
Date
Expense category (Food/Shopping/Transportation/Bills/Entertainment)
Notes
Category Management
Purpose: To help users classify income and expenses.
Functions:
Create new category
Edit category
Delete category
Classify category (income / expense)
Statistics and Reporting
Purpose: To help users monitor their financial situation.
Functions:
Calculate total income
Calculate total expenses
Compare income and expenses
Analyze expenses by category
Analyze data by time (day / month / year)
Display:
Pie chart (expenses by category)
Bar chart (income vs expenses by month)
Budget Management
Purpose: To control spending.
Functions:
Set monthly budget
Set budget by category
Track spending against budget
Alert when nearing budget limits
Search and Filter
Purpose: To help users quickly find information.
Functions: 
Search income / expenses
Filter by: Date, Month, Category, Amount range
Expense Reminders
Purpose: To help users maintain consistent records.
Functions:
Daily expense logging reminders
Bill payment reminders
Data Export and Backup
Purpose: To protect and reuse data outside the system.
Functions:
Export reports to PDF
Export data to Excel
Backup data
Restore data
V. Technologies Used 
Front-end: React + Vite
Back-end: NodeJS + ExpressJS
Database: MongoDB
